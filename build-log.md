## Session closeout routine

Repeat at the end of each build day or filming session:

1. Finish the build-day entry, including decisions and the next step.
2. Add or complete each session in `03_footage/footage-log.md`; note useful clips,
   timestamps, and intended episode.
3. Update the active episode's storyboard or footage table with what changed or was
   captured.
4. Update counters and the project README summary if they changed.
5. Add a changelog entry only for a durable hardware, code, wiring, story, or edit
   change; link to the build-log entry and relevant footage.
